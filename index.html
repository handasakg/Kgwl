רשימת עובדים במערכת

איך מגדירים הרשאות?

בעריכת עובד בחר/י תבנית מוכנה (מנהל מערכת / עובד / צופה) ואז סמן/י או בטל/י הרשאות בודדות - התבנית תהפוך ל"מותאם אישית".

מסכים ופעולות ללא הרשאה פשוט לא מוצגים לעובד. מנהל מערכת תמיד בעל גישה מלאה, וחייב להישאר לפחות אחד פעיל.

שים לב: ההגנה פועלת בצד הדפדפן. להגנה אמיתית על נתוני הענן יש להגדיר גם Rules ב-Firebase.

חיבור מסד נתונים בענן (Firebase Realtime DB)

חבר את המערכת ל-Firebase בחינם לקבלת סנכרון בזמן אמת מכל הטלפונים והמחשבים

איך זה עובד? בעבודה רגילה, הנתונים נשמרים בדפדפן המקומי. ברגע שתזין כאן את פרטי ה-Firebase שלך, המערכת תסתנכרן אוטומטית לענן וכל עובד מכל טלפון יראה את אותם הנתונים מעודכנים במיידי!

הסיסמה מוגדרת כברירת מחדל בקובץ, כך שכל מכשיר מאושר מתחבר ומסתנכרן אוטומטית.

אחסון קבצים חיצוני (Supabase Storage - חינם)

קבצים מצורפים להזמנות / תעודות / השאלות יעלו לענן חיצוני עד 50MB לקובץ ו-1GB סה"כ, ויהיו זמינים מכל מכשיר

הוראות הגדרה (חד-פעמי, כ-5 דקות)
  1. נכנסים ל-supabase.com, נרשמים בחינם (בלי כרטיס אשראי) ויוצרים Project.
  2. ב-Project Settings ← API מעתיקים את Project URL ואת מפתח anon public לשדות למעלה.
  3. ב-SQL Editor מריצים:
insert into storage.buckets (id, name, public) values ('inventory-files','inventory-files',true) on conflict (id) do nothing;
create policy "inv read"   on storage.objects for select to anon using (bucket_id='inventory-files');
create policy "inv upload" on storage.objects for insert to anon with check (bucket_id='inventory-files');
create policy "inv delete" on storage.objects for delete to anon using (bucket_id='inventory-files');

שים לב: הקבצים נגישים רק למי שמחזיק בקישור המדויק (שם אקראי), אך אינם מוגנים בסיסמה. לא מומלץ להעלות מסמכים רגישים במיוחד.

Google Drive ומערכת ראשית להעלאת קבצים

בוחרים לאן יעלו קבצים חדשים. כל עובד מעלה אחרי כניסה עם שם משתמש וסיסמה, והמנהל קובע בלשונית "עובדים והרשאות" מי רשאי להעלות (הרשאה: העלאת קבצים)

הוראות הגדרה (חד-פעמי, כ-5 דקות)
  1. נכנסים ל-script.google.com עם חשבון Google שהדרייב שלו ישמש לאחסון, ולוחצים "פרויקט חדש".
  2. מוחקים את הקוד הקיים, מדביקים את הקוד שלמטה, ובשורה הראשונה מחליפים את הסיסמה בסיסמה סודית משלך.
  3. לוחצים "פריסה" ← "פריסה חדשה" ← סוג: "אפליקציית אינטרנט". "הפעל בתור": אני. "מי יכול לגשת": כל אחד. מאשרים הרשאות לדרייב.
  4. מעתיקים את כתובת ה-Web App (נגמרת ב-/exec) לשדה למעלה, מזינים את אותה סיסמה בשדה Token, לוחצים "שמור" ואז "בדוק חיבור".
  5. בוחרים "Google Drive" כמערכת ראשית ושומרים. מעכשיו כל קובץ שעולה במערכת נשמר בתיקייה "מערכת מלאי - קבצים" בדרייב שלך.

חשוב: כדי שקבצים ייפתחו לכל משתמש / אורח בלי התחברות ל-Google, הקוד למטה חייב לכלול את הפעולה get. אם כבר פרסת סקריפט ישן - הדבק את הקוד המעודכן ובצע "פריסה" ← "ניהול פריסות" ← עריכה ← גרסה: "גרסה חדשה" (הכתובת נשארת זהה).

קוד Apps Script:
const TOKEN = 'CHANGE-ME-TO-A-SECRET';
const FOLDER_ID = ''; // אופציונלי: מזהה תיקייה קיימת. ריק = ייווצר תיקייה "מערכת מלאי - קבצים"
function folder_() {
  if (FOLDER_ID) return DriveApp.getFolderById(FOLDER_ID);
  const it = DriveApp.getFoldersByName('מערכת מלאי - קבצים');
  return it.hasNext() ? it.next() : DriveApp.createFolder('מערכת מלאי - קבצים');
}
function out_(o) {
  return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON);
}
function doPost(e) {
  try {
    const d = JSON.parse(e.postData.contents);
    if (d.token !== TOKEN) return out_({ ok: false, error: 'סיסמת הגישה (Token) שגויה' });
    if (d.action === 'ping') return out_({ ok: true, folder: folder_().getName(), url: folder_().getUrl() });
    if (d.action === 'upload') {
      const blob = Utilities.newBlob(Utilities.base64Decode(d.data), d.type || 'application/octet-stream', d.name || 'file');
      const f = folder_().createFile(blob);
      f.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
      return out_({ ok: true, id: f.getId(), url: f.getUrl() });
    }
    if (d.action === 'get') { // החזרת תוכן הקובץ - מאפשר צפייה בלי התחברות ל-Google
      const f = DriveApp.getFileById(d.id), b = f.getBlob();
      return out_({ ok: true, name: f.getName(), type: b.getContentType(), data: Utilities.base64Encode(b.getBytes()) });
    }
    if (d.action === 'delete') { DriveApp.getFileById(d.id).setTrashed(true); return out_({ ok: true }); }
    return out_({ ok: false, error: 'פעולה לא מוכרת' });
  } catch (err) { return out_({ ok: false, error: String(err) }); }
}

שים לב: הקבצים נשמרים כ"כל מי שיש לו את הקישור יכול לצפות" (שם מזהה אקראי), ללא הגנת סיסמה. הסיסמה (Token) גלויה למשתמשים המחוברים למערכת. לא מומלץ להעלות מסמכים רגישים במיוחד. גודל קובץ מקסימלי: כ-30MB.
